القرآن الكريم

Qur'an PC

Version 1.1.1 · Works offline

An offline Arabic Quran reader for Windows, Linux and the web, laid out in the 604 pages of the Madinah Mushaf, with the Fihris, Azkar, Duas and the notes and tables at the back.

Install from the browser

In Chrome, Edge or Brave, click the Install button in the toolbar, or the install icon in the address bar. On an iPhone, tap Share, then Add to Home Screen. The install is only a few MB and then works offline.

Shortcuts

← / → turn the page (the Mushaf reads right to left, so ← is the next page) · on a phone, swipe right for the next page and left for the previous one · Ctrl+F search · Ctrl + / − zoom · Alt+← / → previous / next surah · F11 fullscreen · double-click an ayah to bookmark it.

Please note

Please check the text against a trusted printed mushaf before relying on it for study or teaching.
